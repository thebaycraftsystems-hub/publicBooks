## Add another document

1. Upload the file into this repo (for example `MyNotes.pdf`).
2. Use the **real file name** in the link, not the words YOUR_FILE_NAME.

Examples that already work:

- https://github.com/thebaycraftsystems-hub/publicBooks/blob/main/Git_Fundamentals.md
- https://github.com/thebaycraftsystems-hub/publicBooks/blob/main/Git_Fundamentals.docx
